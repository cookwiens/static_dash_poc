Overview

The Health Indicator Dashboard was created by the Lawrence-Douglas County Informatics Department. If you have questions about the indicators, methods described below, or would like to request a special analysis, please don't hesitate to contact us. Our contact information is available on the Lawrence-Douglas County Public Health website.

Note Indicators will be updated regularly, but may not necessarily have the most recent data available from a given data source. The methods used for creating the dashboard are described in the sections below.

Evaluating trends

The "Current" tab on each indicator tile shows the most recent value for the indicator in large text followed by one of the following color-coded shape indicating trend:

Symbol Trend
▲ Increasing; in the right direction
▲ Increasing; in the wrong direction
▼ Decreasing; in the right direction
▼ Decreasing; in the wrong direction
■ No trend or "flat"

To assess whether there is a trend, we use a simple algorithm that takes into account all of the observations shown on the indicator tile. First, we only evaluate trends for indicators with at least 6 observations. If at least 6 observations are available, we assess the trend in two ways: (1) we compute the linear slope across the entire time period and (2) we find the average of the first 3 (pre) and last 3 (post) observations and calculate the percent change. If the slope of the linear fit or the change from pre to post agrees with the direction in which we desire the trend to move, the arrow is colored green. If it is going in the wrong direction, it is colored red. If the data is "noisy" (if the standard deviation multiplied by 0.5 exceeds the slope), or if the change from baseline is less than 3%, we decide there is no trend (■).

Essence Queries

The ESSENCE Syndromic Surveillance system is a key data source for a number of health indicators on this site. We query ESSENCE data using the ESSENCE API (application programming interface) and the pynssp python library. The specific queries we use for measures on this site have the following parameters.

Heat-related (Annual) - Heat-related ED Visits (Annual)
  • datasource: va_er
  • geography: ks_douglas
  • geographySystem: region
  • medicalGroupingSystem: essencesyndromes
  • timeResolution: yearly
  • hasBeenE: 1
  • ccddCategory: cdc sexual violence v3
